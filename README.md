Python Authentication System

Cybersecurity Portfolio – Project 01

A Python-based authentication system demonstrating fundamental cybersecurity concepts.

Features
Username and password authentication.
SHA-256 password hashing.
Three-attempt login limit.
Account lockout.
Security event logging.
Technologies
Python 3
hashlib
logging
Installation
bash
git clone https://github.com/ellioteastwood-ui/Password-checker-logging.git
cd Password-checker-logging
python passchecker.py

Skills Demonstrated
Authentication and access control
Cryptographic hashing
Brute-force mitigation
Security monitoring and logging
Python programming
